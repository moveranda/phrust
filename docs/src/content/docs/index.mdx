## What Phrust is

Phrust is a learning project. The physics follows *University Physics with Modern Physics* (Young & Freedman), and each chapter is turned into engine code with tests and runnable examples. Rendering uses WebGPU, so the same code targets native desktops and the browser (`wasm32-unknown-unknown`).
